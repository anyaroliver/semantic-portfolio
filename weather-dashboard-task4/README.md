# Weatherly — Task 4
A responsive weather dashboard built with HTML, CSS, and vanilla JavaScript.

## Run in VS Code
1. Extract the ZIP and open this folder in VS Code.
2. Open `index.html`.
3. Use the Live Server extension: right-click the file → **Open with Live Server** (or click **Go Live**).
4. Search for a city or use a quick city button.

## Concepts
- Fetch API, async/await, JSON parsing
- Geocoding city names to coordinates, then retrieving weather
- Error handling for HTTP errors, network failures, and unknown cities
- Dynamic DOM rendering of nested current and daily forecast data
- Responsive design and accessible live status announcements

## API attribution
Uses Open-Meteo geocoding and forecast endpoints. No API key is needed for this demo. Keep the visible Open-Meteo attribution.
