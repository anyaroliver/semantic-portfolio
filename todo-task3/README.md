# Daymark — To-do List (Task 3)

## Run in VS Code
1. Extract the ZIP and open this folder in VS Code.
2. Open `index.html`.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and choose **Open with Live Server**, or click **Go Live**.

## Features
- Create, read, update, and delete tasks (CRUD)
- Mark tasks active or completed
- All / Active / Completed filters and completed-task clearing
- Automatic persistence through `window.localStorage`
- Dynamic DOM rendering and delegated event listeners
- Responsive layout and accessible labels / live status announcements

Tasks persist in the same browser profile and origin; they are not synced across devices.
